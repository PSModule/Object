# Object

Object is a PowerShell module for working with PowerShell objects.

## Installation

Install the module from the PowerShell Gallery:

```powershell
Install-PSResource -Name Object
Import-Module -Name Object
```

## Documentation

Documentation is published at [psmodule.io/Object](https://psmodule.io/Object/).

Use PowerShell help and command discovery for module details:

```powershell
Get-Command -Module Object
Get-Help <CommandName> -Examples
```
